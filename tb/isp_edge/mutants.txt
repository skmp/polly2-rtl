# tb/isp_edge/mutants.txt: the planted bugs of the ISP edge path in rtl/v1/isp (PLAN M2 "Mutants", conventions.md 7.7),
# run by tools/gate/mutants.py (make isp-edge-mutants). Every one must be caught by its probe, the testbench in quick
# mode with 20,000 random jobs and 20,000 random descriptors, and the unchanged folder must pass first. The mutants of
# the M1 library the edge path uses (the cull's compare) are in tb/isp_edge/mutants_lib.txt (another folder).
#
# Format: <id> | <file in rtl/v1/isp> | <original fragment> | <mutated fragment> | <probe> [args] | <what it breaks>
# (\n a newline, \| a bar, \\ a backslash in a fragment).
#
# PLAN M2's list, and how each is planted:
#   - EdgeHW's numbers (zeroShift, tieShift, reach, blockMax, cutUnitBits) at their use in the RTL: p2_hw_pkg is
#     generated and shared, so the mutant changes the unit's localparam or instance parameter, not the package;
#   - "708fb8cd's two grids" (ep - 21 for the rows, ep - 27 for the walk) needs two sets of fields the RTL no longer
#     has; it is planted as its two halves: a big edge on 2^(ep - 21), and a big edge on 2^(ep - 27);
#   - "the walk counted from row 0" as written: the raster starts every descriptor at row 0 with r = t0 and walks rows
#     0 .. jf - 1 (the walk's state and its end), giving out only rows jf .. jl (the whole always_ff is the fragment);
#   - "the row-31 shift only with a big edge" through the edges' step exponents (big <=> ep >= 124, isp 8.3).
