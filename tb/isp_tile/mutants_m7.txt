# tb/isp_tile/mutants_m7.txt: the planted bugs of M7's ISP tile units in rtl/v1/isp (PLAN M7 "Mutants", conventions.md
# 7.7), run by tools/gate/mutants.py (make isp-tile-mutants). Every one must be caught by its probe (the per-tile barrier
# must PASS: `!`) and the unchanged folder must pass first. M6's are in tb/isp_tile/mutants.txt.
#
# The probes, on tb/isp_tile/mutant_cases_m7.txt, a phase that takes more than 1M clocks failing (a walk that never
# ends), stopping at the first failure: `tile`, phase-halt mode (every live field at every phase boundary, every SHADE's runs, the feedback, the counts);
# `free`, free-running mode (no halt: the cutter beside the next pass's and entry's work, the run stream under random
# back-pressure).
#
# Format: <id> | <file in rtl/v1/isp> | <original fragment> | <mutated fragment> | <probe> [args] | <what it breaks>
# (\n a newline, \| a bar, \\ a backslash in a fragment).
