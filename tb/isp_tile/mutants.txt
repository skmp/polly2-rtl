# tb/isp_tile/mutants.txt: the planted bugs of M6's ISP tile units in rtl/v1/isp (PLAN M6 "Mutants", conventions.md 7.7),
# run by tools/gate/mutants.py (make isp-tile-op-mutants). Every one must be caught by its probe and the unchanged folder
# must pass first. p2_mem's are in tb/isp_tile/mutants_mem.txt (another folder: rtl/v1/mem).
#
# The probe `tile`: the phase-halt testbench on tb/isp_tile/mutant_cases.txt (pages of the M6 classes, three dumps, scenegen
# seeds 1-200), a phase that takes more than 1M clocks failing (a walk that never ends); `vary`: the same with the VRAM
# model's random latency (--vramvary 7).
#
# Format: <id> | <file in rtl/v1/isp> | <original fragment> | <mutated fragment> | <probe> [args] | <what it breaks>
# (\n a newline, \| a bar, \\ a backslash in a fragment).
@dir rtl/v1/isp ISP_DIR
@obj ISP_TILE_OBJDIR
@probe tile isp-tile-build tb --phase-limit 1000000 @tb/isp_tile/mutant_cases.txt
@probe vary isp-tile-build tb --phase-limit 1000000 --vramvary 7 @tb/isp_tile/mutant_cases.txt
