# tb/sort/mutants.txt: the planted bugs of M8's run queue and span sorter in rtl/v1/sort (PLAN M8 "Mutants",
# conventions.md 7.7), run by tools/gate/mutants.py (make sort-mutants). Every one must be caught by its probe and the
# unchanged folder must pass first.
#
# The probes (tb/sort/sort_tb.cpp, SPAN_SORT_CFG 0x101 as every game sets it, stopping at the first failure):
# `subset`, the recorded run streams of tb/sort/mutant_cases.txt (M7's tile subset as p2_isp_cut emitted it: the cases
# where 95 and 97 places put runs out of order); `random`, 4,000 random streams (4 blocks), every back-pressure class (the
# slow cutter's among them).
#
# Format: <id> | <file in rtl/v1/sort> | <original fragment> | <mutated fragment> | <probe> [args] | <what it breaks>
# (\n a newline, \| a bar, \\ a backslash in a fragment).
@dir rtl/v1/sort SORT_DIR
@obj SORT_OBJDIR
@probe subset sort-build tb --cfg 0x101 --max-fails 1 @tb/sort/mutant_cases.txt
@probe random sort-build tb --cfg 0x101 --random 4000 --block 1000 --max-fails 1
