#
# Format: <id> | <file in rtl/v1/lib/fp> | <original fragment> | <mutated fragment> | <probe> [args] | <what it breaks>
# (\n a newline, \| a bar, \\ a backslash in a fragment).

# Equivalent mutants left out:
#   - p2_fp_cull's `size >= 0x7f800000` culls-all test: FromBits of such a register is bad, and AbsAtMost of a finite det
#     against a bad bound is true anyway, so dropping or changing the test changes nothing (refsw3 has the same
#     redundancy, refsw_tile.cpp CulledBySize).
#   - p2_fp_cut_below's `exp < e` as `exp <= e`: at exp == e the shift is 0 and the tuple is unchanged either way.
#   - p2_fp_rng_add's TSP zero rule at top - 1 == -126 only (depth's test) instead of < -125: a nonzero value below
#     the range plus a zero is below the range, so +0 by P2_RNG_LIM_SUM whether the rule fires or not.
