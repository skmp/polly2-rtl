# How PLAN M3's list is planted:
#   - DepthHW's numbers (tileBits, pairBits) at their use in p2_isp_depth_tile (p2_hw_pkg is generated and shared);
#   - "the sample point swapped": the start at the other sample point; "708fb8cd's corner model": the start at the
#     centre whatever HALF_OFFSET[0] says, and with HALF_OFFSET[0] = 0 the block's S stepped back half a pixel (h = -1:
#     t = S + (2i - 1) DX + (2j - 1) DY), REG at the centre's start;
#   - "an infinite determinant not 0" as the mean's key (refsw3 708fb8cd stored the first corner's word; the tile does
#     not see the corners, any key that is not 0 is the bug);
#   - "the forced start not stepped": the overflowed start's plane as CONST 0 (revision 1's ovf 1 had 0 at the first
#     pixel and one word elsewhere; either is not stepped);
#   - "a finite slope below zero rounded down" one unit of 2^102 down whatever the cut dropped (the RTL keeps no
#     "dropped" flag; on the grid both agree only where nothing was cut).
